# DeQuizMa coding conventions

Apply these rules to every code change in this project.

- Follow the existing architecture and keep the implementation cohesive.
- Refactor when it improves the design or readability. Keep the code maintainable, reusable, testable, and responsive.
- Reuse existing behavior when it fits. Avoid duplication and abstractions that make the code harder to follow.
- Write clear names and explicit code a human developer can read easily. Do not add code comments.
- Open a pull request and use Conventional Commits.
